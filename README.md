# 마비노기 모바일 원재료 수량 계산기

 ## 설명서
- 철괴는 철 광석, 광석 두 가지 중 하나로 선택하시면 되십니다
- 위의 이유로 철괴가 필요한 경우 철 광석과 광석 두가지가 모두 나옵니다. 둘 중 하나만 선택해서 채집하시면 되십니다.
- 아이템 이름을 한글로 입력 후 뜨는 아래의 리스트에서 선택해주세요. 초성 검색도 한글로 검색하셔야 합니다.
- 물품 추가는 우측 **추가 버튼**을 눌러 입력란을 추가하신 뒤 작성하시면 됩니다.
- 제작할 아이템의 총 수량을 입력 후 **계산하기**를 클릭하면 자동으로 필요 수량이 입력 됩니다.
- 이미 보유 중인 수량은 **보관중인 재료** 란에 숫자로만 입력하시면 자동으로 계산이 됩니다.

## **$\color{red}{\textbf{주의사항}}$**
1. 모바일 마비노기 원재료 수량 계산 사이트에 사용된 일부 컨텐츠의 저작권은 **(주)넥슨코리아**에 있습니다
2. 위의 이유로 이 사이트의 무단 복제 전제를 금지합니다
3. 모바일 마비노기 원재료 수량 계산 사이트는 비영리, 개인 사이트입니다.
4. **서비스 이용 제한**
  > [!CAUTION]
  > 너무 잦은 새로고침은 아이피 차단의 원인이 됩니다.
